# Nacho endpoints required

## /api/trending/movies
- To fetch trending movies from Trakt API.
## /api/trending/shows
- To fetch trending shows from Trakt API.



## /api/user/create
- To create a new user in the Nacho Time system.

## /api/user/:user_id
- GET To fetch user details by user ID.
- PUT To update user details by user ID.
- DELETE To delete a user by user ID.

## /api/user/:user_id/history
- GET To fetch watch history for a specific user.
- POST To add a new entry to the user's watch history.
- DELETE To remove an entry from the user's watch history.
